# ChinaTradeResolve — план трафика и конверсии после v3.7.58

## Важный вывод
Нулевая посещаемость не может быть объяснена только дизайном: плохой экран снижает конверсию уже пришедших посетителей, но не создаёт нулевой входящий поток. v3.7.58 исправляет доверие и конверсию; трафик требует отдельного запуска каналов.

## До привлечения трафика
1. Проверить, что Privacy показывает контролёра «Эдуард Цаголов» и рабочий контактный email; затем добиться `/ready` = HTTP 200.
2. Пройти production smoke test без изменения DNS/секретов вне утверждённой процедуры.
3. Проверить Метрику/Search Console/Webmaster: показы, клики, поисковые запросы, источники и заявки должны различаться.
4. Не оценивать эффективность по «заявок нет» без показов/визитов: сначала установить, есть ли показы и клики.

## Первые 30 дней
- Неделя 1: 5–10 полезных ответов в профильных сообществах без спама; ссылки — только там, где правила разрешают и контекст действительно подходит.
- Неделя 2: 2–3 экспертных публикации из существующих guides: evidence checklist, supplier not shipped, product quality dispute.
- Неделя 3: партнёрские контакты с sourcing/inspection/logistics специалистами, которым нужен нейтральный evidence-preparation ресурс.
- Неделя 4: оставить только каналы, которые дают показы/визиты/заявки; не масштабировать канал без измеряемого результата.

## Метрики воронки
1. Search impressions / community post views.
2. Site visits by UTM source.
3. Landing → form start.
4. Form start → submit.
5. Submit → suitable case.
6. Suitable case → completed assessment.

Если показатель 1 равен нулю, проблема не в форме. Если 1–2 есть, но form start почти нулевой — проблема в оффере/доверии. Если form start есть, а submit нет — проблема в форме.

## Запрет на ложное доверие
Не публиковать вымышленные отзывы, сертификаты, квалификации, количество клиентов или проценты успеха. Учебный пример должен всегда оставаться явно учебным.
