# Яндекс Вебмастер и Метрика — настройка ChinaTradeResolve v3.7.50

## 1. Сначала подключите домен

1. В Render откройте сервис → Settings → Custom Domains → Add Custom Domain.
2. Добавьте `chinatraderesolve.com` и `www.chinatraderesolve.com`.
3. В панели регистратора создайте DNS-записи ровно по значениям, которые показывает Render.
4. Не задавайте `PUBLIC_BASE_URL` и не включайте редирект, пока новый домен не открывается по HTTPS.
5. Когда домен работает, задайте на Render:
   - `PUBLIC_BASE_URL=https://chinatraderesolve.com`
   - `ENABLE_CANONICAL_REDIRECT=true`

## 2. Разрешите индексацию

После проверки главной страницы, `/privacy`, `/robots.txt` и `/sitemap.xml` задайте:

`SEARCH_INDEXING_ENABLED=true`

После перезапуска `/robots.txt` должен содержать `Allow: /` и ссылку на `https://chinatraderesolve.com/sitemap.xml`. Полная готовность `/ready` по-прежнему контролирует публичные функции, но больше не блокирует поисковую индексацию из-за временно выключенного ИИ или почты.

## 3. Подтвердите сайт в Яндекс Вебмастере

1. Добавьте `https://chinatraderesolve.com`.
2. Выберите подтверждение метатегом.
3. Скопируйте только значение `content`, без всего тега.
4. Сохраните его в Render как `YANDEX_SITE_VERIFICATION`.
5. После перезапуска откройте исходный код главной страницы и проверьте `meta name="yandex-verification"`.
6. Нажмите «Проверить» в Яндекс Вебмастере.

## 4. Передайте карту сайта

В Яндекс Вебмастере откройте Индексирование → Файлы Sitemap и добавьте:

`https://chinatraderesolve.com/sitemap.xml`

## 5. Настройте Яндекс Метрику

1. Создайте счётчик для `https://chinatraderesolve.com`.
2. Скопируйте числовой номер счётчика.
3. Сохраните его в Render как `YANDEX_METRIKA_ID`.
4. Перезапустите сервис и проверьте счётчик в интерфейсе Метрики.

Код использует локальный CSP-совместимый загрузчик, не включает Вебвизор и публикует раскрытие об аналитике в политике конфиденциальности.

## 6. Ускорьте обнаружение страниц

1. Создайте ключ: `python -c "import secrets; print(secrets.token_hex(16))"`.
2. Сохраните его как `INDEXNOW_KEY`.
3. Выполните в Render Shell: `python scripts/submit_indexnow.py`.
4. В Яндекс Вебмастере отправьте на переобход главную, `/ru/guides` и основные русские статьи.
